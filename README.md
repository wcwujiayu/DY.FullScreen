# DY.FullScreen

让抖音首页视频撑满整块屏幕的 Theos 插件，仅在 **抖音 iOS 40.7.0** 上测试。
**仅供学习交流，禁止用于商业用途。**

> **版本 0.5.10** ｜ 目标环境：iOS 16.1 · 抖音 40.7.0 · TrollStore + TrollFools 注入
> 抖音设置项名称：**「视频全屏启动」** ｜ 入口：抖音原生「设置」页内

---

## 功能总览

### 全屏

- 首页视频 / 图集画布撑满整块屏幕（视频列表、互动层、播放器画面三处高度补偿）
- 我-喜欢 / 我-作品 / 收藏 / 推荐 / 聊天分享的作品：详情页视频同样撑满整屏，底部评论 / 输入栏透明覆盖在视频上；互动层锁在「整屏 − 底栏」，UI 不位移
- 底栏 TabBar 背景透明，按钮保留可见可点
- 进度条黑色背景线清除
- 信息流直播卡片：视频撑满卡片，账号与文案停在底栏上方
- 开播前推流预览：播放器高度匹配，左下角文案 / 账号信息平移到 TabBar 上方

### 透明化

- 「相关搜索」/「合集」/「大家都在搜」胶囊卡片去灰底
- 各页面自带的贴底黑条（我-作品 / 我-喜欢 / 收藏 / 详情页）：铺满宽、贴近底部、高度 20~170 的统一处理
- 详情页铺在视频后面的纯黑底板（如 `AWEAwemeDetailTableView`）清成透明
- 视频详情页底部评论 / 输入栏背景透明（含评论输入胶囊、聊天分享底栏胶囊的深色圆角层）
- 含文字 / 控件的贴底条只清深色背景，按钮与文字保留可点
- 兼容毛玻璃底栏（`UIVisualEffectView` 置空，内容保留）
- 只清背景：文字、图标、点击区域一律不动
- 保护视频文案 / 描述 label（YYLabel 富文本），不被去灰底逻辑误清
- 普通聊天会话窗口不做处理（聊天里点开的分享视频详情仍做底栏透明）
- 直播间与开播预览不受影响

### 设置与诊断

- 抖音原生设置页「视频全屏启动」开关
- 诊断面板：各 Hook 安装状态、调整次数、版本匹配情况

### 保护机制

- 真正进入直播间时，跳过所有尺寸与透明处理
- **透明化只改背景（颜色 / 毛玻璃 / 渐变）**，绝不调整或移动 UI 布局：账号 / 文案 / 进度条 / 右侧按钮一律留在原位
- 详情页撑满只作用于「承载视频」的容器，互动层单独锁回「整屏 − 底栏」，避免 UI 被一起拉高
- 透明化节流带处理上限与最小间隔，避免把主线程跑满
- 关掉开关可一次性还原所有已改视图，无需重启抖音

## 安装

1. 从 Release 下载 `DY.FullScreen.dylib`
2. 在 TrollFools 中停用并移除旧版，再注入新 dylib
3. 打开抖音「设置」页，找到「视频全屏启动」开关
4. 测试前先停用其他会修改视频尺寸 / 布局的插件，避免 Hook 冲突

## 构建

支持三种打包方案，产物由 GitHub Actions 自动构建：

```bash
make package SCHEME=rootless FINALPACKAGE=1   # TrollFools 常用
make package SCHEME=rootful  FINALPACKAGE=1
make package SCHEME=roothide FINALPACKAGE=1
```

版本号唯一来源为 `control` 的 `Version` 字段，CI 动态读取，不重复维护。

## 项目结构

| 模块 | 职责 |
|---|---|
| `Tweak.m` | 入口：constructor 与 hook 安装调度 |
| `DYFSCommon` | 常量、runtime 工具、跨模块状态、抖音私有类名清单、视图探测与背景清除基础函数 |
| `DYFSContext` | 上下文守卫（个人主页 / 直播间 / 推流预览 / 详情页 / 聊天会话） |
| `DYFSLayout` | 尺寸修正（首页全屏、直播卡片、详情页容器拉满） |
| `DYFSChrome` | 底栏背景透明、进度条黑线 |
| `DYFSTransparency` | 透明化调度入口（开关、节流、关开关后还原） |
| `DYFSCardTransparency` | 「相关搜索」/「合集」胶囊卡片去灰底 |
| `DYFSBottomChrome` | 全局底栏 / 贴底黑条 / 互动右栏清理 |
| `DYFSSettings` | 设置入口与运行诊断 |

抖音改版导致类名变化时，只需更新 `DYFSCommon.m` 与 `DYFSContext.m` 顶部的常量清单。
各模块 `.m` 不得超过 500 行（CI 强制），超了请继续拆分而不是往里塞。
