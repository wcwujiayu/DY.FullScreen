# DY.FullScreen

让抖音首页视频撑满整块屏幕的 Theos 插件，仅在 **抖音 iOS 40.7.0** 上测试。
**仅供学习交流，禁止用于商业用途。**

> **版本 0.5.5** ｜ 目标环境：iOS 16.1 · 抖音 40.7.0 · TrollStore + TrollFools 注入
> 抖音设置项名称：**「视频全屏启动」** ｜ 入口：抖音原生「设置」页内

---

## 功能总览

### 全屏

- 首页视频 / 图集画布撑满整块屏幕（视频列表、互动层、播放器画面三处高度补偿）
- 底栏 TabBar 背景透明，按钮保留可见可点
- 进度条黑色背景线清除
- 开播前推流预览的播放器高度匹配（不平移文案与按钮）
- 信息流直播卡片：视频撑满卡片；账号与文案停在底栏上方；「进入直播间 + 横屏」按钮组整体水平居中
  - 0.4.11 修复：直播卡片不再被误判为「真实直播间」，账号/文案/点赞区上移与底栏透明在信息流里正常生效
  - 0.4.12 修复：取不到 audienceVC 时直接处理卡片自身子树，并在下一帧补一次上移，避免抖音后续重排把文案又压回底栏
  - 0.4.13 诊断：新增「直播卡片处理次数」与一次性跳过原因日志（区分是 hook 没跑还是跑了没命中）
  - 0.4.14 重写：完全对齐 DYYY 的 3 个核心 hook（互动层高度限制 / 播放器 view 补高 / 底栏递归透明），去掉此前会挡掉整段高度修正的自定义判定
  - 0.4.15 修复：`AWEPlayInteractionViewController` 高度限制与全局 `setFrame:` 补高严格限定为「只在信息流直播卡片内生效」，普通视频（我-喜欢 / 收藏 / 我-作品 / 详情页）不再出现位移
  - 0.5.4 修复：开播预览卡片（进入直播间前的预览页）左下角文案 / 账号信息整体平移到底栏上方，不再压在 TabBar 上


### 透明化

- 「我-作品 / 我-喜欢 / 收藏」与详情页自带的贴底黑条：贴底、铺满宽、高度 20~170 的统一处理（0.4.12 新增，这类页面之前根本没触发透明化；0.4.13 起只在个人主页与详情页生效，不碰首页信息流）
- 文章类视频：不再用「子树有文字就跳过」的保守判断，改为与 DYYY 一致——播放器根 view 无条件补高，互动层由高度限制统一收口（0.4.13 的「阅读文章」位移保护改为由互动层尺寸收口）
- 含文字 / 控件的贴底条只层层清掉深色背景，按钮与文字保留可点
- 「相关搜索」/「合集」胶囊卡片背景
- 兼容毛玻璃底栏（`UIVisualEffectView` 置空，内容保留）
- 只清背景：文字、图标、点击区域一律不动
- 0.5.3 起显式保护视频文案 / 描述 label（如 `AFDRichAwemeFullPageHeaderDescriptionLabel` 等 YYLabel），防止被去灰底逻辑误清
- 0.5.4 修复「我-喜欢 / 我-作品 / 与朋友聊天分享的作品」三类视频下方底栏背景透明化漏网：此前只清纯背景条、且要求完全贴底，而评论输入胶囊与聊天分享底栏的深色来自「含文字容器自身的渐变 / 圆角层」，且底栏下方还有独立输入条导致不完全贴底。现改为对含文字容器也清理自身背景子层（按钮 / 图标图除外），并把「接近底部」阈值放宽到 130pt
- 0.5.4 修复：开播预览卡片底部信息面板（账号 / 文案）整体平移到 TabBar 上方，不再与底栏重叠
- 0.5.5 修复：上述平移改为 `transform` 实现（不再改 frame），并补一次延迟重试 —— 原实现会被抖音后续 Auto Layout 压回，表现为时好时坏；底边计算改用 `center + bounds`，不掺 transform，多次调用结果稳定
- 0.5.5 新增：我-喜欢 / 我-作品 / 聊天分享的作品 / 详情页的视频画面同样撑满整屏，底部评论 / 输入栏透明覆盖在视频上（只拉「视频画面」这一条链，含按钮的互动层保持原高度不动，避免按钮位移）
- 0.5.5 修复：普通聊天会话窗口整个跳过透明化处理。此前聊天窗口底部输入栏的毛玻璃被兜底逻辑误判为「贴底深色条」隐藏，导致底栏透明一块（聊天里点开的分享视频详情不受影响，仍做底栏透明）
- 直播间与开播预览不受影响

### 设置与诊断

- 抖音原生设置页「视频全屏启动」开关
- 诊断面板：各 Hook 安装状态、调整次数、版本匹配情况
- 0.5.x 起已移除侧边栏入口

### 保护机制

- 真正进入直播间时，跳过所有尺寸与透明处理
- 个人主页不参与尺寸修正，仅做透明化
- 直播卡片内容识别只处理含文字 / 控件的视图，视频层与背景层不碰

## 安装

1. 从 Release 下载 `DY.FullScreen.dylib`
2. 在 TrollFools 中停用并移除旧版，再注入新 dylib
3. 打开抖音「设置」页，找到「视频全屏启动」开关
4. 测试前先停用其他会修改视频尺寸 / 布局的插件，避免 Hook 冲突

## 构建

支持三种打包方案，产物由 GitHub Actions 自动构建：

```bash
make package SCHEME=rootless FINALPACKAGE=1   # TrollFools 常用
make package SCHEME=rootful  FINALPACKAGE=1
make package SCHEME=roothide FINALPACKAGE=1
```

版本号唯一来源为 `control` 的 `Version` 字段，CI 动态读取，不重复维护。

## 项目结构

| 模块 | 职责 |
|---|---|
| `Tweak.m` | 入口：constructor 与 hook 安装调度 |
| `DYFSCommon` | 常量、runtime 工具、跨模块状态、抖音私有类名清单 |
| `DYFSContext` | 上下文守卫（个人主页 / 直播间 / 推流预览 / 详情页） |
| `DYFSLayout` | 尺寸修正 |
| `DYFSChrome` | 底栏背景透明、进度条黑线 |
| `DYFSSettings` | 设置入口与运行诊断 |
| `DYFSTransparency` | 底栏 / 卡片透明化 |
| `DYLiveFeedFullscreen` | 信息流直播卡片 |

抖音改版导致类名变化时，只需更新 `DYFSCommon.m` 与 `DYFSContext.m` 顶部的常量清单。
