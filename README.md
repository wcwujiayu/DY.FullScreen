# DY.FullScreen

用于调整 DY UI 的 Theos/Logos Tweak，仅在 **40.7.0** 中测试。
**仅供学习交流，禁止用于商业用途。**

> 版本 **0.4.0**。目标环境：iOS 16.1、抖音 iOS 40.7.0、TrollStore + TrollFools。原生设置项主标题为"首页全屏"，下方副标题为"胖胖专属"。

## 0.4.0 变更说明

**移除两项实测无效的背景透明处理**（及其全部依赖逻辑）：

- "相关搜索" / "合集" 卡片去灰底
- 评论页面底部输入栏去灰底

连带删除了支撑它们的整棵视图递归扫描代码。收益是：`Tweak.m` 体积减少约 25%，并且不再在 `layoutSubviews` 回调中执行全树遍历——首页滑动时的额外开销随之消失。

**保留的能力**：

- 首页视频 / 图集的画布撑满（视频列表、互动层、播放器画面三处高度修正）
- 底栏 TabBar 背景透明（按钮保留可见可点）
- 进度条黑色背景线清除
- 开播前推流预览的播放器容器高度匹配（不平移文案与按钮）
- 直播间识别保护：已进入直播间时跳过尺寸与透明处理
- 侧边栏"胖胖专属"入口 + 抖音原生设置页开关

**同时修复的问题**：

| 问题 | 处理 |
|---|---|
| `build.yml` 硬编码版本号，改 `control` 后 CI 必然失败 | 改为从 `control` 动态读取，产物名统一用变量 |
| 灰度 `UIColor` 取色失败（黑线清不掉） | `getHue:` 失败时回退 `getWhite:alpha:` |
| 侧边栏入口 `superview.superview.superview` 固定三级跳 | 改为向上有界查找能容纳按钮的最近祖先 |
| 底栏背景递归扫描被 4 个高频回调重复触发 | 合并为每个主线程回合最多执行一次 |
| 抖音版本不匹配只打日志、界面无感知 | 写入状态并在诊断面板显示"版本匹配：一致 / 不一致" |
| 散落的魔法数字（tag、按钮尺寸） | 提取为常量 |

## 自动构建

仓库使用 Theos/Logos 构建流程，生成 rootful、rootless、roothide 三种 Debian 包，以及 TrollFools 使用的动态库。推送代码后查看仓库 Actions 页面中的构建任务；成功后在该次运行记录底部 Artifacts 下载构建结果。

版本号**只从 `control` 文件的 `Version` 字段读取**，CI 不再重复维护。预期文件包括三种 `.deb`、`DY.FullScreen_<version>.dylib`、`DY.FullScreen.dylib`、`DY.FullScreen-<version>-TrollFools.zip` 和 `SHA256SUMS.txt`。

版本标签（例如 `v0.4.0`）用于触发 GitHub Release 发布流程。

## 安装与测试

1. 从 Actions Artifacts 下载构建包并解压。
2. 在 TrollFools 中停用并移除旧版，再注入本次构建的 `DY.FullScreen.dylib`（或 ZIP 内的 dylib）；.deb 是 Debian 包格式，不是首选注入文件。
3. 打开抖音侧边栏，在系统"设置"入口旁点击"胖胖专属"，检查开关和"运行诊断"。
4. 测试时先停用其他会修改视频尺寸/布局的插件，避免 Hook 冲突。
5. 重点检查：首页视频是否撑满屏幕、底栏背景是否透明、进度条是否有残留黑线、开播预览页的文案与按钮位置是否被推歪。
6. 诊断面板会显示各 Hook 的安装状态与调整次数，以及当前抖音版本与测试版本（40.7.0）是否一致——不一致时布局可能异常。
7. 若闪退或错位加重，立即在 TrollFools 停用本插件并重启抖音。
